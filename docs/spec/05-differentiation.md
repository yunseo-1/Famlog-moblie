# 5. 추천 차별화 기능

경쟁 서비스와 비교해 FamLog만의 가치를 키우는 기능을 추천한다. 선정 기준은 ① 가족(특히 부모님 세대)에게만 의미가 큰 것, ② 이미 있는 데이터(채팅·일정·장소·사진)를 재사용해 1인 개발로 만들 수 있는 것, ③ 프라이버시 위험이 낮은 것이다.

| ID | 기능 | 내용 | 왜 차별화인가 | 단계 |
| --- | --- | --- | --- | --- |
| DIF-01 | 부모님 편한 모드 | 큰 글씨·큰 버튼 홈(가족 채팅 / 오늘 일정 / 사진 보기 3개), 음성 입력 기본, 복잡한 메뉴 숨김. 자녀가 원격으로 켜 줄 수 있다(부모 동의) | 가족 앱의 실제 장벽은 부모님 사용성. 카톡보다 쉬운 경험 | 🟦 v1.1 (v1.0은 글자 200% 대응) |
| DIF-02 | 음성 메시지 + 받아쓰기 | 녹음 메시지를 텍스트로 함께 표시(STT). 받아쓴 텍스트도 자동 등록 인식 대상 | 타자가 힘든 부모님 말도 일정·맛집으로 연결 | 🟦 v1.1 |
| DIF-03 | 가족 날짜 투표 | "언제 모일까?" 후보 날짜 → 구성원 투표 → 확정 시 일정 후보 생성. "토요일에 시간 돼?"를 AI가 감지하면 [투표 만들기] 제안 | 자동 인식의 "아직 안 정해진 질문" 공백을 메움 | 🟦 v1.1 |
| DIF-04 | 음력·경조사 기념일 | 음력 생신·제사를 매년 양력으로 자동 변환해 표시, 2주 전 "준비할 일" 후보(선물·장보기·예약) | 한국 가족 특화. 일반 캘린더가 잘 못하는 부분 | 🟦 v1.1 |
| DIF-05 | 가족 장보기 목록 | "올 때 우유 사와" → 장보기 항목 후보. 체크하면 "아들이 우유 샀어요" 알림 | 함께 사는 가족의 매일 쓰는 기능 → 재방문 | 🟦 v1.1 |
| DIF-06 | 그날의 우리 | 1년 전·2년 전 오늘의 사진·일정 회상 카드 (그룹 설정으로 끄기) | 쌓인 기록이 가치가 되는 순간, 이탈 방지 | 🟦 v1.1 |
| DIF-07 | 가벼운 안부 체크인 | 하루 한 번 "잘 지내요" 버튼+이모지. 위치 추적 없음. 본인이 켜면, 정한 기간 응답이 없을 때 본인이 지정한 가족에게만 부드러운 알림 | 떨어져 사는 부모님 안부를 감시 없이 확인 | 🟦 v1.2 |
| DIF-08 | 우리 가족 맛집 지도 카드 | 지역별 맛집을 이미지 카드·웹 링크로 내보내기 (가게 주소만, 개인 정보 없음) | 친척·지인 공유로 자연 유입 | 🟦 v1.2 |
| DIF-09 | 월간 가족 신문 인쇄 | 스토리를 A4 신문 PDF로 (FUN-01 앞당김) | 부모님께 종이로 드리는 경험 | 🕒 |
| DIF-10 | 일정 겹침 안내 | 등록 시 참여자의 겹치는 일정 표시 (SCH-05) | 가족 일정 조율의 작은 불편 해결 | ✅ P2 |

> **범위 원칙:** 차별화 기능은 v1.0 출시 일정을 지키기 위해 대부분 v1.1 이후로 둔다. v1.0에서는 데이터 구조만 미리 열어 둔다 (todos.kind, schedules.calendar_type, messages.type=VOICE 등).
