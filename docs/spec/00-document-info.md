> **이 문서를 읽는 방법**
>
> AI 코딩 도구에는 문서 전체가 아니라 **기능 ID 단위**(예: SCH-02)로 해당 절을 전달한다. 각 기능은 "기능 요구사항(4장) → 데이터(10장) → API(11장) → 인수 기준(18장)"이 같은 ID로 연결된다. 바이브 코딩 순서와 프롬프트는 20장에 있다.
