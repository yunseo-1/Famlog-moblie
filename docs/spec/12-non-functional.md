# 12. 비기능 요구사항

| 분류 | 요구사항 |
| --- | --- |
| 성능 | 메시지 전달 p95 500ms, 목록 API p95 300ms, 앱 콜드 스타트 2초 이내, 채팅방 스크롤 60fps |
| AI 지연 | 후보 카드는 대화 멈춘 뒤 1분 이내, 팸봇 첫 토큰 3초 이내(스트리밍) |
| 영상 생성 | 2분 영상 5분 이내, 진행률 표시, 완료 푸시 |
| 가용성 | 월 99.5%. AI·영상 워커 장애가 채팅·일정에 영향 없음 |
| 규모(MVP 목표) | 가입자 1,000명, 그룹 300개, 동시 접속 200 |
| 비용 | 인프라 + AI 월 상한 설정, 80% 도달 시 알림 (금액은 19장 오픈 이슈) |
| 접근성 | 터치 영역 48dp, 시스템 글자 크기 200%에서 깨지지 않음, TalkBack 라벨, 대비 4.5:1, 색만으로 정보 전달 금지(구성원 색 + 이름) |
| 오프라인 | 최근 메시지·일정 로컬 캐시, 미전송 메시지 자동 재전송, 업로드는 WorkManager로 재시도 |
| 호환성 | minSdk 26, **targetSdk 36**, 16KB 메모리 페이지 대응(네이티브 라이브러리 포함 SDK 버전 확인), 화면 크기·폴더블 대응, 다크 모드 |
| 언어·시간 | 한국어 단일(문자열 리소스 분리는 해 둔다), 표시 시간대 Asia/Seoul, 저장 UTC |
| 관측 | 서버 구조화 로그 + traceId, 메트릭(Actuator/Prometheus), 앱 크래시(Crashlytics), AI 호출 비용 대시보드 |
| 백업 | DB 일 1회 자동 백업, 7일 보관, 출시 전 복구 리허설 1회 |
