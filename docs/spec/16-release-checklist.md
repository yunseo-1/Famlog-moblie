# 16. 출시 준비 체크리스트

## 16.1 Google Play

- 개인 개발자 계정: 비공개 테스트 **12명 이상, 14일 연속** 참여 후 프로덕션 신청
- targetSdk 36, AAB 업로드, 16KB 페이지 호환 확인, Play App Signing
- 스토어 등록 정보(아이콘, 스크린샷, 짧은·자세한 설명), 카테고리 결정(Communication 또는 Social — Social이면 아동 안전 기준 적용)
- 데이터 보안 양식(수집 항목·공유 여부·암호화·삭제 요청 가능), 개인정보처리방침 URL, 계정 삭제 웹 URL
- 콘텐츠 등급 설문, 대상 연령(13세 이상 일반), 광고 없음 선언
- 권한 선언: 사진은 Photo Picker, 위치는 포그라운드만, 알림
- AI 생성 콘텐츠: 앱 내 신고 기능 확인, 아동 안전 기준 웹페이지·담당 연락처(Social 선택 시)

## 16.2 법·정책 문서

- 개인정보처리방침(8장 내용 반영, 국외 이전·AI 처리·위치·E2EE 미적용 명시), 이용약관, 위치기반서비스 이용약관, 아동 안전 기준(CSAE) 페이지 — 웹에 게시
- 위치기반서비스사업 신고 여부 확인 및 신고 (필요 시 사업자 등록 포함 검토)
- KIPRIS 상표 확인 (FamLog / 팸로그, 9류·38류)
- 개인정보 보호책임자 지정(개발자 본인), 문의 채널(이메일) 개설
- 출시 전 개인정보·법률 전문가 검토 1회

## 16.3 운영

- 운영 서버 TLS, 백업·복구 리허설, 비용 알림, 에러 알림, 사고 대응 runbook 모의 훈련
- 관리자 도구로 신고 처리 흐름 확인, 기능 플래그로 위치·AI 기능 끄기 확인
