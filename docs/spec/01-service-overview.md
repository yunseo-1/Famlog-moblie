# 1. 서비스 개요

## 1.1 서비스 정의

**FamLog(팸로그)**는 가족 전용 단체 채팅을 중심으로 구성원별 일정, 맛집·좋은 장소, 사진·동영상을 하나로 연결하고, AI가 대화와 활동을 정리해 **월간 가족 스토리**와 **YouTube에 올릴 수 있는 월간 영상**을 만들어 주는 가족 라이프 플랫폼이다.

## 1.2 핵심 차별점

- **채팅이 곧 기록이 된다:** 대화 속 일정·기념일·할 일·맛집을 AI가 찾아 "등록할까요?" 카드로 제안한다. 사용자가 승인해야만 등록한다(자동 저장 없음).
- **가족 관계를 아는 앱:** 아빠·엄마·아들·딸 같은 가족 역할을 기준으로 일정·장소를 보고, "아빠가 이번 주에…" 같은 말을 담당자로 연결한다.
- **한 달이 이야기와 영상으로 돌아온다:** 월말에 그달의 일정·장소·사진·대화 흐름으로 스토리와 16:9 영상을 만든다.
- **부모님도 쓰기 쉬운 앱:** 큰 글씨 모드, 음성 메시지 받아쓰기, 음력 기념일 등 세대 차이를 줄이는 기능(5장).
- **프라이버시 우선:** 폐쇄형 그룹, AI 분석 동의(그룹·개인), 감정·관계 기능은 기본 꺼짐, 자녀 데이터 자동 공개 금지.

## 1.3 대상 사용자

- 떨어져 사는 성인 자녀와 부모, 함께 사는 3\~5인 가족
- 친가·외가처럼 여러 가족 그룹에 동시에 속한 사용자
- 디지털에 익숙하지 않은 부모·조부모 세대 (큰 글씨, 단순한 흐름, 음성 입력 필요)

## 1.5 경쟁 포지셔닝

카카오톡 단체방은 대화는 편하지만 일정·장소가 대화에 묻힌다. 일반 공유 캘린더는 대화와 분리되어 있어 부모님이 직접 입력하지 않는다. AI 비서형 서비스(예: 카카오 카나나)는 개인 비서 중심이다. FamLog는 **가족 단위 데이터 + 승인형 자동 등록 + 월간 회고 콘텐츠**에 집중해 "가족의 기록 앱"으로 자리 잡는다.
