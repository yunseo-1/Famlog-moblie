## 4.9 추후 구현 (🕒 기획만)

데이터만 쌓을 수 있게 설계하고 화면은 만들지 않는다. 감정·관계 기능은 모두 선택 참여, 기본 꺼짐, 구성원 비교·순위 없음.

| ID | 기능 | 요약 |
| --- | --- | --- |
| TONE-01 | 따뜻한 말투로 변환 전송 | 스타일 선택 → 변환 문장 2\~3개 미리보기 → 골라서 전송. 숫자·일시 변경 시 경고, 자동 전송 없음 |
| FUN-01\~05 | 가족 신문·방송·회고록·성장 다이어리·타임캡슐 | 월간 스토리를 신문 PDF로, AI 내레이션 영상, 부모님 인터뷰 질문, 자녀 성장 기록, 지정일 열람 |
| EMO-01\~04 | 감정 온도계·사랑지수·칭찬 통장·감사 캘린더 | 본인이 직접 입력한 것만 사용, 채팅에서 감정을 추측하지 않는다 |
