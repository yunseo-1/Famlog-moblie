# 3. 화면 구성

## 3.1 내비게이션

- 하단 탭 5개: **채팅 · 캘린더 · 장소 · 앨범 · 이야기** (앨범·이야기 탭은 v1.0에서 "곧 만나요" 안내 화면)
- 채팅 탭만 전체 그룹 목록을 보여주고, 나머지 탭은 **현재 가족 그룹** 데이터만 보여준다. 앱 바의 "우리 가족 ▾"로 그룹을 바꾼다.
- 팸봇(v1.2)은 앱 바 ✨ 아이콘 또는 채팅방 `@팸봇` 멘션으로 부른다.
- 상세 화면은 하단 탭을 숨기고 뒤로가기를 보여준다. Android 15+ edge-to-edge, 예측형 뒤로가기를 지원한다.
- 디자인: Figma "FamLog - Wireframe & Design Patterns" (fileKey `1nECE5iK8TBDRSydCasO1j`), 노드 맵은 `famlog/docs/design/figma-map.md`.
