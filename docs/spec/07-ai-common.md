## 7.2 AI 원칙

- **제안 → 확인:** AI 결과는 항상 사용자 확인 후 저장·전송한다.
- **구조화 출력 + 서버 검증:** JSON 스키마 강제, 날짜 범위·구성원 ID·장소 존재를 서버에서 검증. 실패는 버린다.
- **근거 제시:** 스토리 문장·팸봇 답변에는 출처, 근거가 없으면 "찾지 못했어요".
- **투명성 표시 (인공지능기본법):** 앱 첫 AI 기능 사용 전 "이 기능은 생성형 AI를 사용합니다" 고지. AI 생성 결과(후보 카드, 스토리, 영상, 팸봇 답변)에는 "AI 제안 / AI가 쓴 초안 / AI로 만든 영상" 표시. 영상은 메타데이터에도 생성 표시.
- **신고 (Google Play AI 생성 콘텐츠 정책):** 모든 AI 결과에서 앱을 나가지 않고 [신고]할 수 있고, 신고는 필터·프롬프트 개선에 쓴다.
- **비용 관리:** 배치 처리, 그룹별 일일 호출 상한, 월 전체 비용 상한. 상한 초과 시 인식 기능만 유지하고 나머지는 다음 날로.
- **장애 격리:** 재시도 3회 후 DLQ. 채팅·일정은 AI 장애 영향 없음 (Redis Streams 분리).
- **교체 가능:** `LlmClient` 인터페이스 뒤에 제공자를 숨기고, 프롬프트는 버전 파일로 관리 (`prompts/extract_v1.md`).

## 7.3 품질 측정

| 지표 | 계산 | 목표(MVP) |
| --- | --- | --- |
| 제안 수락률 | (저장 + 수정 후 저장) / 전체 카드 | 60% 이상 |
| 수정 없이 저장 비율 | 저장 / (저장 + 수정 후 저장) | 70% 이상 |
| 날짜 변환 정확도 | 평가 데이터셋 기준 | 90% 이상 |
| 오탐률 | 무시(틀린 내용) / 전체 카드 | 15% 이하 |

가상 가족 대화 평가 데이터셋(50건 이상, `famlog-backend/worker/evals/`)을 만들고 프롬프트·모델을 바꿀 때마다 회귀 평가한다. 실제 사용자 대화는 평가 데이터에 쓰지 않는다.
