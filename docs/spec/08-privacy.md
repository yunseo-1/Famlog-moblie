# 8. 개인정보 보호 사양

> **설계 원칙 (Privacy by Design)**
>
> ① 최소 수집: 기능에 꼭 필요한 것만 받는다 (이메일·전화번호·실명을 받지 않는다). ② 기본값은 보호: 위치·AI 분석 확장·감정 기능은 사용자가 켜야 동작한다. ③ 가족이라도 개인: 그룹에 공유한 것만 가족이 본다. ④ 사용자가 통제: 내보내기·삭제·분석 제외를 앱 안에서 직접 한다.

※ 이 장은 개발 요구사항이며 법률 자문이 아니다. 개인정보처리방침·약관·위치기반서비스 신고는 출시 전 전문가 검토를 받는다(19장).

## 8.2 수집 항목·목적·보관 기간

| 항목 | 목적 | 구분 | 보관·파기 |
| --- | --- | --- | --- |
| 소셜 계정 식별자(제공자 ID), 닉네임 | 회원 식별·로그인 | 필수 | 탈퇴 30일 후 파기 |
| 프로필 사진 | 가족에게 표시 | 선택 | 변경·탈퇴 시 파기 |
| 출생연도·월 | 만 14세 이상 확인 | 필수 | 탈퇴 시 파기 |
| 가족 역할·호칭·캘린더 색 | 구성원별 일정·자동 인식 | 필수(그룹별) | 그룹 탈퇴 시 파기 |
| 메시지·사진·동영상·음성 | 채팅 서비스 | 서비스 이용 | 본인 삭제 시 즉시, 탈퇴 시 메시지는 익명화·미디어는 선택 삭제 |
| 사진 촬영 시각 | 앨범 정리 | 서비스 이용 | 미디어와 동일 |
| 사진 위치(EXIF GPS) | 여행 앨범·장소 연결 | 선택(위치 동의) | 동의 철회 시 즉시 삭제 |
| 일정·할 일·장소 | 가족 공유 | 서비스 이용 | 작성자 삭제 또는 그룹 삭제 시 |
| 기기 정보(푸시 토큰, 모델, OS, 앱 버전) | 알림·보안·오류 대응 | 필수 | 로그아웃·탈퇴 시 파기 |
| 접속 기록(IP, 일시) | 보안·부정 이용 방지 | 자동 생성 | 3개월 (통신비밀보호법) |
| 위치정보 이용·제공 사실 확인자료 | 위치정보법 의무 | 자동 생성 | 법정 기간 보관 후 파기 |
| AI 후보·피드백 기록 | 등록 기능·품질 측정 | 서비스 이용 | 1년 또는 그룹 삭제 시 |
| 신고 내역 | 운영·분쟁 대응 | 자동 생성 | 처리 후 1년 |
| 동의 이력(종류·버전·일시) | 동의 증빙 | 자동 생성 | 탈퇴 후 법정 기간 |

- 받지 않는 정보: 실명, 전화번호, 이메일(제공자가 주더라도 저장하지 않음), 주소, 연락처 목록, 상시 위치, 광고 ID.
- 크래시 수집(Crashlytics)은 사용자 ID 대신 무작위 설치 ID만 쓰고, 로그에 메시지 내용을 넣지 않는다.

## 8.3 동의 구조

| 동의 | 시점 | 구분 | 철회 |
| --- | --- | --- | --- |
| 이용약관, 개인정보 수집·이용(필수) | 가입 | 필수 | 탈퇴 |
| AI 분석 (개인) | 그룹에서 AI 분석이 처음 켜질 때 안내, 기본 동의 상태는 그룹 설정을 따르되 개인이 언제든 제외 | 선택 | 설정 > AI 분석에서 내 메시지 제외 |
| 개인정보 국외 이전 (LLM·STT 제공자) | AI 분석 안내와 함께 고지(이전 국가·받는 자·항목·목적·보유 기간·거부 방법) | 고지/동의 (법률 검토로 확정) | AI 분석 제외로 거부 |
| 위치기반서비스 이용약관 + 개인위치정보 수집·이용 | 내 주변 검색, 사진 위치 사용을 처음 켤 때 | 선택 | 설정에서 끄기 → 저장된 사진 위치 삭제 |
| 알림 권한 | 첫 그룹 입장 후 (Android 13+ 시스템 권한) | 선택 | 시스템 설정 |
| 감정·관계 기능 (추후) | 기능을 켤 때 | 선택 | 기능 끄기 시 데이터 삭제 |

모든 동의는 `consents` 테이블에 종류·문서 버전·일시로 기록한다. 약관이 바뀌면 다음 실행 때 변경 사항을 보여주고 다시 동의를 받는다.

## 8.5 만 14세 미만

- **v1.0 (권장안):** 만 14세 이상만 가입한다. 출생연도·월로 확인하고, 미만이면 "보호자와 함께 사용하는 기능은 곧 제공돼요" 안내 후 가입을 막는다. Play Console 대상 연령도 13세 이상 일반 사용자로 설정하고, 아동 대상 앱(Families 프로그램)으로 등록하지 않는다.
- **v1.1 (검토 후 구현):** 그룹의 부모 구성원이 법정대리인 동의를 하는 흐름. 법정대리인 확인 방법(본인 인증 등), 자녀 계정 기본 제한(외부 공유·YouTube·팸봇 끔, 위치 끔), 보호자 동의 기록을 법률 검토 후 확정한다.
- 자녀(성인 포함)의 데이터는 부모에게 자동 공개하지 않는다. 그룹에 공유한 것만 보인다.

## 8.6 위치정보 처리

| 수집 지점 | 처리 방식 |
| --- | --- |
| 장소 공유(가게·관광지 좌표) | 사람의 위치가 아니라 장소 정보. 일반 데이터로 저장 |
| 내 주변 검색(PLC-04) | 현재 좌표를 요청 처리에만 쓰고 **저장하지 않는다.** 서버 로그·트레이스에 좌표를 남기지 않는다. 앱은 대략적 위치(ACCESS_COARSE_LOCATION)를 먼저 요청하고, 백그라운드 위치는 요청하지 않는다 |
| 사진 위치(EXIF GPS) | 개인 설정 "사진 위치 사용" **기본 꺼짐.** 켠 사용자의 사진만 위치를 `media_assets.location`에 따로 저장. 원본 파일은 업로드 처리 단계에서 GPS 태그를 제거해 보관하므로, 다른 가족이 내려받은 파일에는 위치가 없다 |
| 외부 공유(스토리 링크·영상) | 주소는 시·구까지만, 좌표 없음 |
| 확인자료 | 개인위치정보를 이용할 때마다 `location_access_logs`(누가·언제·어떤 기능)를 자동 기록 |

> **출시 전 할 일:** 위 처리가 위치기반서비스사업 신고 대상인지 확인하고, 대상이면 방송미디어통신위원회에 신고한다(1인 창조기업·소상공인 특례 확인). 신고 없이 위치 기능을 내보내지 않도록 v1.0의 PLC-04·사진 위치는 **기능 플래그**로 끄고 켤 수 있게 만든다.

**만들지 않는 기능(비목표):** 가족 실시간 위치 공유, 위치 추적, 도착 알림. 감시로 오해받기 쉽고 법적 부담이 크다.

## 8.7 AI·LLM 데이터 처리

- **최소 전송:** 분석 구간 메시지만 보낸다. 사용자 이름 대신 `M1`, `M2` 같은 임시 ID와 역할·호칭만 보낸다(가명 처리). 응답의 임시 ID는 서버가 실제 ID로 바꾼다.
- **마스킹:** 전화번호·계좌번호·카드번호·주민등록번호·이메일 패턴을 전송 전에 치환한다.
- **제공자 조건:** API 데이터를 모델 학습에 쓰지 않는 조건, 보관 최소화(가능하면 무보관 옵션), 데이터 처리 계약. 제공자·국가는 처리방침에 공개한다.
- **로그:** 프롬프트·응답 원문을 저장하지 않는다. 모델·프롬프트 버전, 토큰 수, 지연 시간, 결과 상태만 남긴다.
- **임베딩(v1.2):** 원문 메시지가 삭제되면 해당 임베딩도 함께 삭제한다.
- **분석 제외:** 그룹 AI 꺼짐 또는 개인 제외 메시지는 큐에도 넣지 않는다 (AR-10).

## 8.8 가족 안의 프라이버시

- 가족 구성원도 서로 다른 개인이다. 알림 미리보기 숨기기, 앱 잠금(SEC-01)을 제공한다.
- 감정·관계 기능은 선택 참여, 기본 꺼짐. 구성원 간 비교·순위·"누가 답장을 안 했다" 같은 표시는 만들지 않는다.
- 안부 체크인(DIF-07)은 본인이 켜고, 알림 받을 사람과 기간을 본인이 정한다.
- 구성원이 나가면 그 사람은 더 이상 그룹 데이터를 볼 수 없다. 남은 가족에게는 그가 올린 기록이 "나간 구성원" 이름으로 남는다.
- 그룹 관리자도 다른 구성원의 AI 분석 제외 설정을 볼 수만 있고 바꿀 수 없다.

## 8.9 파기 절차

- 계정 삭제 요청 → 즉시 로그아웃·세션 폐기·푸시 토큰 삭제 → 30일 유예(복구 가능) → 배치 작업이 개인정보 삭제, 메시지 작성자 익명화, 선택한 미디어 삭제(S3 객체 포함), 임베딩 삭제.
- 백업에 남은 데이터는 백업 보관 기간(7일)이 지나면 자연 삭제되며, 복구 시 삭제 대상 목록을 다시 적용한다.
- 파기 작업 결과는 감사 로그에 건수만 기록한다.
