# 2. 사용자 및 권한

## 2.1 구성 개념

- **사용자(User):** 앱 계정 1개. 여러 가족 그룹에 속할 수 있다.
- **가족 그룹(Family Group):** 초대 코드로만 가입하는 폐쇄형 그룹. 그룹당 단체 채팅방 1개 자동 생성. 그룹당 최대 20명, 사용자당 최대 10개 그룹.
- **가족 역할(Family Role):** 그룹 안에서의 관계. 구성원별 일정 조회와 자동 인식의 담당자 추정에 쓴다.
  - 값: FATHER(아빠), MOTHER(엄마), SON(아들), DAUGHTER(딸), GRANDFATHER(할아버지), GRANDMOTHER(할머니), OTHER(기타)
  - 표시 호칭(예: 큰아들, 막내)과 캘린더 색을 따로 둔다. 같은 역할이 여러 명이면 호칭으로 구분한다.
  - 같은 사람이 그룹마다 역할이 다를 수 있다 (친가 그룹에서는 아들, 우리 집 그룹에서는 아빠).

## 2.2 그룹 권한 역할

| 기능 | OWNER | ADMIN | MEMBER |
| --- | --- | --- | --- |
| 채팅·사진 전송, 일정·장소·할 일 등록, 후보 카드 처리 | ✅ | ✅ | ✅ |
| 남이 등록한 항목 수정·삭제 | ✅ | ✅ | 본인 것만 |
| 초대 코드 발급·재발급 | ✅ | ✅ | ❌ |
| 구성원 내보내기, 권한 변경 | ✅ | ✅ (OWNER 제외) | ❌ |
| 그룹 AI 분석 켜기/끄기, 그룹 기능 설정 | ✅ | ✅ | ❌ |
| 스토리 공개, 외부 공유 링크·YouTube 업로드 | ✅ | ✅ | ✅ (본인 생성분) |
| 그룹 삭제, OWNER 위임 | ✅ | ❌ | ❌ |

- 모든 그룹 데이터 API는 요청자가 그 그룹의 활성 구성원인지 검사한다 (9.3 객체 단위 인가).
- OWNER가 탈퇴하려면 OWNER를 위임하거나 그룹을 삭제해야 한다. 그룹에 혼자 남은 OWNER가 탈퇴하면 그룹은 30일 뒤 삭제된다.
- 구성원이 내보내지면 그가 올린 메시지·사진은 그룹에 남고(가족 기록 보존), 본인은 더 이상 볼 수 없다. 본인이 원하면 탈퇴 전 "내가 올린 사진 함께 삭제"를 선택할 수 있다.
