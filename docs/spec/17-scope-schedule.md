# 17. 릴리스 범위와 일정

## 17.1 v1.0 (MVP) 포함

- 소셜 로그인, 만 14세 이상 확인, 기기 관리, 계정 삭제(앱·웹), 데이터 내보내기, 동의 관리
- 가족 그룹 생성·초대·전환·역할·호칭·색, 구성원 관리
- 가족 단체 채팅(텍스트·사진·동영상·읽음·답장·공감·푸시), 신고
- 구성원별·전체 일정, 반복, 공휴일, 할 일
- 장소 공유, 지역별·구성원별 목록, 별칭 장소, 지도(위치 기능은 플래그)
- ⭐ 채팅 기반 자동 등록(일정·기념일·할 일·장소)
- 앨범(월별 정리·여행 앨범·중복/흔들림 정리), 월간 가족 스토리(초안·수정·공개), 월간 영상(BGM AI 자동 선택·직접 선택, 저장·공유, 인물 동의) — v2.1에서 v1.1 → v1.0으로 이동
